# Новая студия за 6 минут

Код не меняется: студия — это папка `tenants/<slug>/` (один файл настроек + фото).

## 1. Создать папку (≈30 с)

```bash
pnpm tenant:new studio-pro --name "Студия PRO" --accent "#4690FF" --timezone Europe/Moscow
```

Появится `tenants/studio-pro/` из шаблона `tenants/_template` (или `--from ngx-detailing`,
чтобы взять готовую студию за основу).

## 2. Заполнить `business.json` (≈3 мин)

Редактор подсказывает поля по `schemas/business.schema.json`. Главное:

| Поле | Пример | Заметка |
|---|---|---|
| `name`, `tagline`, `description` | «Студия PRO» | показываются на главной |
| `contacts.address / phone / mapUrl` | | «Как нас найти» |
| `timezone` | `Europe/Moscow` | расписание и напоминания считаются в часовом поясе студии |
| `theme.accent` | `#4690FF` | один акцентный цвет, контраст текста подбирается сам |
| `hours` | `"mon": ["09:00-20:00"]`, `"sun": []` | пустой список — выходной |
| `closedDates`, `specialHours` | `"2026-12-31"` | праздники и сокращённые дни |
| `resources` | посты / боксы | одна машина на пост в один момент времени |
| `services[].duration` | `"90m"`, `"5h"`, `"2d"` | `2d` держит пост 2 дня подряд |
| `services[].buffer` | `15` | минуты на уборку после работы, `0` — без буфера |
| `services[].price`, `priceFrom` | `18000`, `true` | «от 18 000 ₽» |
| `services[].resources` | `["box-1","box-2"]` | на каких постах можно делать |
| `booking.cancelCutoffHours`, `cancellationPolicy` | `3` | правила отмены для клиента |
| `infoCards` (3 шт.), `gallery` | | карточки и фото работ |

## 3. Фото (≈1 мин)

Положите в `tenants/studio-pro/images/`: `hero.jpg` (большое фото машины, от 1600 px по ширине),
`logo.png`, `icon.png` (квадрат от 512 px — иконка на экран «Домой»), фото услуг и галереи по путям
из `business.json`. Размер и формат конвейер приведёт сам (WebP, несколько размеров).

## 4. Проверить и опубликовать (≈1 мин)

```bash
pnpm tenant:validate studio-pro
pnpm tenant:publish studio-pro --owner-email owner@studio.ru     # пароль будет напечатан один раз
```

Публикация идемпотентна: повторный запуск обновляет услуги, цены и фото, но **не трогает** записи,
оплаты и то, что владелец уже поменял в кабинете (`--force` — вернуть значения из файла).

## 5. Выложить (≈30 с)

```bash
git add tenants/studio-pro public/s/studio-pro && git commit -m "Студия PRO" && git push
```

Vercel пересоберёт сайт; студия откроется по адресу `https://<сайт>/s/studio-pro/` в режиме
**«Образец»**: записи помечаются как тестовые, уведомления не уходят.

## 6. Запустить в работу

Когда владелец проверил данные:

```bash
pnpm tenant:verify studio-pro --url https://<сайт> --activate
```

`verify` проверяет телефон, адрес, фото, часы, услуги с постами и ненулевыми ценами, наличие владельца,
публичный API, оболочку страницы, манифест, иконки и service worker. Только если всё в порядке, студия
переводится в рабочий режим, тестовые записи удаляются.
